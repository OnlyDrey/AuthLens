AuthLens {{VERSION}} - installer folder {{BUILD_ID}} (source commit {{SHA}})
=============================================================================

This folder (Installer\{{VERSION}}\{{BUILD_ID}} on the build machine) holds the verified Setup programs and the packaged tooling of one build.
To move a release to another machine, use the portable deployment package instead of copying this folder:

1. On the build machine: .\build.ps1 -OutputRoot C:\AuthLens -ZipPackage, or for this existing build
     .\backend\scripts\New-AuthLensPackage.ps1 -Candidate C:\AuthLens\Build\{{VERSION}}\{{BUILD_ID}}
   This writes C:\AuthLens\Packages\AuthLens-{{VERSION}}-{{BUILD_ID}}.zip (a flat archive: both Setup programs, Expand-AuthLensPackage.ps1,
   README.txt, installer-manifest.json, package-manifest.json, SHA256SUMS.txt and Tools\) and reports the ZIP SHA-256 in build-summary.json and
   the .zip.sha256 file beside it.
2. Copy only the ZIP to C:\AuthLens on the target machine. Verify and extract it with the package's own script, which checks the optional ZIP
   SHA-256, rejects unexpected, absolute or traversing entries, never overwrites C:\AuthLens\AuthLens-{{VERSION}}-{{BUILD_ID}}, extracts into a
   temporary .x-* folder, verifies every file against SHA256SUMS.txt and the release identity, and only then renames it into place:
     powershell -NoProfile -ExecutionPolicy Bypass -File <Expand-AuthLensPackage.ps1> -Package C:\AuthLens\AuthLens-{{VERSION}}-{{BUILD_ID}}.zip -Destination C:\AuthLens -ExpectedSha256 <ZIP SHA-256 from the build report>
   Re-verify an extracted folder at any time (a folder that exists is not proof of a complete extraction):
     powershell -NoProfile -ExecutionPolicy Bypass -File C:\AuthLens\AuthLens-{{VERSION}}-{{BUILD_ID}}\Expand-AuthLensPackage.ps1 -VerifyOnly -ExtractedDirectory C:\AuthLens\AuthLens-{{VERSION}}-{{BUILD_ID}}
3. Server: run AuthLens-{{VERSION}}-Server-Setup.exe from an elevated session (upgrade: /CONFIGFILE=<deploy.json> /OPERATION=Upgrade).
   Desktop: run AuthLens-{{VERSION}}-Desktop-Setup.exe as the user.
4. Independent recovery before an upgrade: Tools\recovery\New-AuthLensRecoveryBundle.ps1 in the extracted package (here:
   installer-tools-*\recovery\), or Service Manager: Backup and recovery keys > Create a recovery bundle. A verified bundle proves the backup
   opens with the copied key; it is not a restore rehearsal (Tools\recovery\Test-AuthLensRestoreRehearsal.ps1, isolated).

Integrity is not authenticity: SHA-256 checksums prove the files match the recorded digests, not who published them. The Setup programs are
signed only when the release report says so; check them with Get-AuthenticodeSignature. Full guide: docs/deployment/WINDOWS_DEPLOYMENT.md.
