AuthLens {{VERSION}} - deployment package {{BUILD_ID}} (source commit {{SHA}})
=============================================================================

This folder (Installer\{{VERSION}}\{{BUILD_ID}}) is self-contained: it needs neither the development repository nor the Build directory.

1. Copy AuthLens-{{VERSION}}-{{BUILD_ID}}.zip and AuthLens-{{VERSION}}-{{BUILD_ID}}.zip.sha256 to C:\AuthLens.
2. Verify and extract with the package's own script (it checks the ZIP SHA-256, rejects unexpected, absolute or traversing entries,
   never overwrites an existing Installer\{{VERSION}}\{{BUILD_ID}}, extracts into a temporary sibling folder (.x-*), verifies every file hash and the
   release identity, and only then renames it into place):
     powershell -NoProfile -ExecutionPolicy Bypass -File <Expand-AuthLensPackage.ps1> -Package C:\AuthLens\AuthLens-{{VERSION}}-{{BUILD_ID}}.zip -Destination C:\AuthLens
   Re-verify an extracted folder at any time (a folder that exists is not proof of a complete extraction):
     powershell -NoProfile -ExecutionPolicy Bypass -File C:\AuthLens\Installer\{{VERSION}}\{{BUILD_ID}}\Expand-AuthLensPackage.ps1 -VerifyOnly -ExtractedDirectory C:\AuthLens\Installer\{{VERSION}}\{{BUILD_ID}}
3. Server: run AuthLens-{{VERSION}}-Server-Setup.exe from an elevated session (upgrade: /CONFIGFILE=<deploy.json> /OPERATION=Upgrade).
   Desktop: run AuthLens-{{VERSION}}-Desktop-Setup.exe as the user.
4. Independent recovery before an upgrade: installer-tools-*\recovery\New-AuthLensRecoveryBundle.ps1 (or Service Manager:
   Backup and recovery keys > Create a recovery bundle). A verified bundle proves the backup opens with the copied key; it is not a restore
   rehearsal (installer-tools-*\recovery\Test-AuthLensRestoreRehearsal.ps1, isolated, never touches the installation).

Integrity is not authenticity: SHA-256 checksums prove the files match the recorded digests, not who published them. The Setup programs are
signed only when the release report says so; check them with Get-AuthenticodeSignature. Full guide: docs/deployment/WINDOWS_DEPLOYMENT.md.
