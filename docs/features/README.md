# Features

- [Dashboard](DASHBOARD.md): overview, lifecycle totals, coverage and source navigation.
- [Role Lookup](ROLE_LOOKUP.md): catalogue, role relationships, transactions and existing Role Comparison and proposed access packages.
- [Users](USER_ACCESS.md): User Directory, profiles and assignment investigation (Users module, formerly User Access).
- [Compare Users](COMPARE_USERS.md): shared/unique roles and role-derived transactions, with source intervals.
- [Account Review](ACCOUNT_REVIEW.md): evidence-based findings and persistent review decisions.
- [Release Access](RELEASE_ROLES.md): PR/PO assignments, filters and the distinct-user matrix (a Users page, formerly Release Roles).
- [Segregation of Duties](SOD.md): risk and activity matrices, Access Explorer, review rules, frozen periods and reports.
- [Reviews](REVIEWS.md): top-level review workspace (Overview, Work Queue, Position Changes, Account Review, Bulk Review, Remediation, Review Periods), routes and compatibility.
- [Reports](REPORTS.md): Review Reports, Access Reports, SoD Reports and Evidence; report availability, configurable columns and the server-side exports.
- [Functional Groups](FUNCTIONAL_GROUPS.md): reviewer-maintained business functions, review integration, filters, access analysis and backup behavior.
- [Saved Filters](SAVED_FILTERS.md): reuse named investigations without storing result datasets.
- [Shared Filters](FILTERS.md): transaction operators, assignment dates and scoped clearing.

Sources are described in [Data & CSV](../data/README.md). Assignments, mapped
transactions, SAP validity/lock and AD status remain separate evidence; none alone
establishes effective authorization, recent usage or licensing entitlement.
